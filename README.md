Marketing Campaign Performance Dashboard

PURPOSE
The purpose of this project is to analyze customer behavior and marketing campaign performance using Power BI. It helps identify spending patterns, purchase channels, customer demographics, and campaign response.

TECH STACK:
Power BI
Power Query
DAX

DATA SOURCE:
Marketing Campaign Dataset (Customer Marketing Data)

DASHBOARD HIGHLIGHTS:
Interactive dashboard with slicers
KPI cards for key business metrics
Customer spending analysis by education
Purchase channel comparison
Average income analysis
Campaign response distribution
Web visits analysis

KEY FINDINGS:
Graduation customers have the highest total spending.
Store purchases are higher than web and catalog purchases.
Only around 15% of customers responded to the marketing campaign.
Average income varies across different marital status groups.
Customers with higher web visits do not always make more purchases.
